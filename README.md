# LocalAgentsOps

ローカルLLM（Ollama）の複数モデルに同じ質問を投げて回答を並べて比較するデスクトップアプリ。必要なときだけ Claude / ChatGPT / Gemini / Grok にも同じ質問を投げられる。APIキーはOSの認証情報ストアに保存され、外部には送信しない。

---

## Windows へのインストール

### 前提: Ollama

**Ollama が必要**。これがないとローカルモデルは一切動かない。

```
winget install --id Ollama.Ollama
```

公式サイト（<https://ollama.com/download>）からのインストールでも可。**0.9.0 以上**が必要（それ未満だとじっくりモードとモデルごとの対応判定が正しく動かない）。古い場合はアプリの ⚙️ から更新できる。

インストールするとタスクトレイに常駐して自動起動する。ターミナルで `ollama serve` を打つ必要はない。

WebView2 ランタイムも必要だが、Windows 11 には標準で入っているため通常は対応不要。

### アプリのインストール

1. `LocalAgentsOps_0.1.0_x64-setup.exe` を実行する
2. **「WindowsによってPCが保護されました」という警告が出る** → 「詳細情報」→「実行」
   - コード署名をしていないため。想定内の挙動で、アプリの不具合ではない
3. インストール先は `%LOCALAPPDATA%\LocalAgentsOps`。**管理者権限は不要**

黙って入れたい場合:

```
LocalAgentsOps_0.1.0_x64-setup.exe /S
```

### アンインストール

```
%LOCALAPPDATA%\LocalAgentsOps\uninstall.exe
```

ダウンロードしたモデルは Ollama 側（`%USERPROFILE%\.ollama`）にあるため、アプリを消しても残る。

## 最初の操作

### 1. Ollama につながっているか確認する

起動すると画面上部にモデルのチップが並ぶ。`Ollama未接続` と出ている場合は Ollama が起動していないので、タスクトレイから起動する。

### 2. モデルを1つ入れる

まだモデルが無ければ **📦（モデルカタログ）** を開く。

- 「このマシンで動かせるおすすめ」に、**この端末で実用速度が出るモデルだけ**が速い順に並ぶ
- 収まらないモデル、遅すぎるモデルは最初から出ない
- 一度どれかのモデルで回答させると、以降は**実測値**で `約18 tok/s` のような推定速度が表示される

最初の1つは **`llama3.2:3b`（約2.0GB）** が無難。この端末で最も速く、動作確認に向く。

コードを書かせたいなら **`deepseek-coder-v2:16b`** が特異な選択肢になる。8.3GBあるが1トークンあたり1.3GBしか読まないMoEモデルなので、サイズの割に非常に速い。

### 3. 質問を送る

1. 画面上部のチップで使うモデルを選ぶ（起動時は最も軽い1つが選択済み）
2. 下の入力欄にプロンプトを書く
3. **Ctrl+Enter で送信**

> **Enter は改行**。送信は Ctrl+Enter。日本語入力の変換確定Enterで誤送信しないための仕様。

チップを複数選べば、同じ質問が並列に投げられて回答が横に並ぶ。

## 操作の要点

| 操作 | 意味 |
|---|---|
| **Ctrl+Enter** | 送信（Enter は改行） |
| **⏹ 中断** | 生成を止めてマシンを解放する。GPUなしの端末では回答に数分かかることがあるため |
| **⏏**（チップ横） | そのモデルをメモリから解放する。チップは一覧を更新するまで隠れる |
| **⚡高速 / 🧠じっくり** | thinking の有無。対応していないモデルは通常応答になる（名前が表示される） |
| **🌐オンライン** | Claude / ChatGPT / Gemini / Grok も比較対象に含める。⚙️でAPIキーの設定が必要 |
| **📦** | モデルカタログ。ダウンロードと、**使う／使わないの切り替え** |
| **⚙️** | Ollamaのバージョンと更新、APIキー、親モデル、1つずつ実行の設定 |

### 使わないモデルを選択肢から外す

📦 の「導入済み」で **「使用しない」** にすると、そのモデルは上部のチップに出なくなる。設定は再起動後も保持される。ダウンロード済みでも普段は使わないモデルがあるとき用。

削除したいわけではないので、モデル自体はディスクに残る。

### オンラインに送るとき

⚙️で**親モデル**を設定しておくと、送信前にローカルモデルが「今回どのサービスを呼ぶ価値があるか」を判断する。呼ぶ価値がないと判断すれば送信しない。有料APIの無駄打ちを減らすための仕組み。

親モデルには軽いモデルを選ぶこと。重いモデルを選ぶと判断のためのプロンプト処理だけで毎回数十秒待たされる（設定画面が警告を出す）。

### 複数モデルを同時に走らせたとき

空きメモリの範囲で並列に実行する。予算を超える分は「待機中（メモリ空き待ち）」と表示されて順番待ちになる。最初の回答を最速で読みたい場合は、⚙️で「1つずつ実行」に切り替える。

## 開発

前提: Rust ツールチェイン、Node.js、Ollama。

```
npm install
npm run tauri dev     # 開発時
npm run tauri build   # 配布用ビルド（Windowsでは NSIS インストーラが出力される）
```

テスト:

```
cd src-tauri
cargo test --lib                        # ロジックのみ
cargo test --lib -- --include-ignored    # 稼働中のOllamaを使う実機テストも含む
```

実機テストには `llama3.2:3b` と `qwen3:0.6b` が必要。

Windows移植の際に実測した数値と設計判断は [WINDOWS_PORT_PLAN.md](WINDOWS_PORT_PLAN.md) に記録してある。
